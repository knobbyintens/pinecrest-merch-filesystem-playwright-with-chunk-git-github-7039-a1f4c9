# Pinecrest Merchandising

Static storefront preview pages and the internal price registry for Pinecrest
Supply Co.

- `shop/` — preview build of the customer storefront.
- `catalog/price_registry.tsv` — price registry for the active cycle.
- `docs/price_audit.md` — live-offer verification ledger.

Branch `main` holds the last shipped cycle. Revision branches hold upcoming
cycle work.
